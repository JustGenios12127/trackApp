# TrackApp

Приложение, в котором задачи ставятся обычным сообщением, как в чате.

Пишешь «купить молоко завтра в 18:00» — TrackApp запоминает дело и напоминает в это время. Команда `/task` показывает все задачи по датам. Внизу четыре вкладки: чат, список, календарь и профиль. Вход по почте, задачи привязаны к аккаунту. Очистка чата их не удаляет.

Клиент — Flutter, папка `app`. Сервер — Supabase, папка `backend`: вход, таблица задач и функция, которая разбирает сообщение.

## Запуск

Нужен Flutter. Свои ключи положи в `app/.env` (в git этот файл не входит):

```
SUPABASE_URL=
SUPABASE_ANON_PUBLIC_KEY=
```

Дальше из папки `app`:

```
flutter pub get
flutter run
```
